# 培训要求与实现对应

来源为 2026 年 6 月《培训任务书》。原文内容转录见 [任务书](taskbook-transcript.md)，原始插图与来源见 [图片集](gallery.md)。

| 培训要求 | 原始基线证据 | 新增参考程序与剩余验证 |
|---|---|---|
| 焦距、视野选型计算 | 任务书给出传感器与工作距离 | 已实现双方向计算与输入检查；实际镜头需实测 |
| 相机通信与采图 | 三个采图工具引用 Device_5，但设备配置中没有该相机 | 保存任务书 IP，提供合成输入；实际相机需配置 |
| H5U TCP 控制与反馈 | 原设备列表未见 PLC 连接 | 新增 Modbus TCP 03/06 报文与客户端；PLC 程序/地址映射需核对 |
| 光源控制器 | 任务书指定串口与 19200 波特率 | 提供接入参数表；具体命令帧未知，不伪造通信完成 |
| 机械人串口控制 | Device_4 串口，115200；主流程已有指令 | 新增指令构造和范围检查；实际型号、终止符和动作需验证 |
| 手眼标定、标准位示教 | 手眼标定数据与九点/示教子流程 | 新增二维平面拟合示例；三维标定和实机精度未验证 |
| 视觉引导抓取与固定点放置 | 取放料子流程保留 | 验证坐标计算与字符串生成；实际运动闭环待接入 |
| 电阻缺陷检测 | 灰度统计工具与模板工具 | 新增灰度方差示例并验证合成缺失案例 |
| 电容颜色匹配 | 基线电容组为灰度统计，不据此宣称已实现颜色检测 | 新增 HSV 颜色比例检测；真实彩色样本待验证 |
| 芯片有无 | 原基线含灰度统计与定位工具 | 新增暗像素比例示例；实测阈值待确定 |
| 原图与结果图保存 | 原 HMI 为空，主流程未证明完整保存链路 | 离线程序已实际生成 SourceImage/RecordImage 文件 |
| 结果表格与用户日志 | 保留原 FAI 表；部分引用不在现主流程 | 已生成 CSV、JSON、JSONL 和 HTML；真实硬件数据待采集 |

主流程目前有 27 个节点，包含机器人控制、示教和取放。算法工具箱有 ATOM_37/41/49，但现主流程中缺少对应调用节点；HMI 的 Tools 列表为空。不能将任务书要求、未接入的工具箱和完整运行系统等同。

本项目补充的 Python 离线程序是独立参考实现，不冒充已经修改并实机验收的原 V+ HMI。完整设备应用还需要相机、PLC、光源和机械手的实际配置与联调。
