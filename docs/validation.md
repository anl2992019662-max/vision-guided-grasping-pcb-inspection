# 验证记录与证据范围

## 已执行的软件检查

本地使用项目声明的依赖执行 34 项 unittest，覆盖选型公式、两方向视野、二维标定、退化点、未参与拟合的点、ROI 边界、颜色检测、Modbus 字节向量、异常/长度/回显、TCP 分段、机器人指令、轴范围、完整结果保存与已有目录保护。检测回归在三组随机噪声种子下检查 18 个已知合成案例。

完整离线演示已执行，6 个合成输入的器件缺陷集合与生成时定义相符。结果包含原图、标注图、组件计算值、CSV、JSON、JSONL 和 HTML。图像和九点坐标的合成标记保留于图内及数据文件，不将这组检查改写为真实生产准确率。

初次演示发现缺失电阻处的线路仍产生灰度方差，过低阈值使其误判为存在；当前示例阈值已调整，并以独立噪声种子回归。这说明阈值必须与实际采图条件验证，不能拿合成阈值直接应用于任意 PCB。

## 原始材料完整性

保留 64 个原始基线文件，逐文件 SHA-256 记于 `manifests/baseline-files.json`。所有原始文件在保留范围内未改写。账户数据库、工程保护配置、DongleConfig.ini、诊断/运行日志、缓存和无关记录未发布。

从原平台序列化图像中提取 4 张独立全幅参考图：2 张标定板、2 张 PCB。按 VPImage8Gray 的 Width/Height/Stride 解码，记录原始像素及 PNG 哈希。它们是原培训资料，不是新增测试结果。任务书保留完整文字转录和 4 张原始插图；原 Word 编辑元数据不随发布包分发。

两张外部器件参考照片按上游 SHA-1 与大小核对，并记录 SHA-256、作者和许可。它们不是作者实物。7 张工程 SVG 为自行绘制的说明图，结果概览根据本项目离线程序输出绘制。

## 已知基线缺口

原 HMI 的 Tools 列表为空；Device.device 仅保存 Device_4 串口；采图工具引用的 Device_5 未在设备列表找到。三个算法工具箱 ATOM_37/41/49 缺少对应主流程调用节点。原 FAI 的 ATOM_54 也不在当前主流程中。保留这些原始资料用于学习，不把文件存在说成完整运行链路已经验收。

`.vpsx` 是平台不透明二进制头，保留原字节及哈希；可读文件和排除项检查不是对商业二进制的完整安全审计。

## 尚需实机验证
