# 通信与硬件接入

## 来源和参数

任务书给定相机 IP `192.168.1.33`、工控机 IP `192.168.1.44`、H5U IP `192.168.1.20` 与 TCP 端口 `502`；控制字地址为 0、结果字地址为 1，均为 Word。上述是实验要求，不是程序已经连接现场设备的记录。

[汇川 H5U 官方资料](https://www.inovance.com/global/content/details_815_403258.html)说明以太网接口支持 Modbus TCP 和 Socket。因此本项目提供 Modbus TCP 03（读保持寄存器）及 06（写单寄存器）参考实现。任务书只写“TCP”，原目录没有 PLC 工程，需要先确认控制器实际采用的协议、单元号、寄存器偏移与运行条件，不能仅根据端口断言地址映射已经正确。

光源为 COM1 或 COM2、19200 bps；命令格式未给出。机械手串口为 COM7；基线串口配置为 115200、8 数据位、1 停止位、无校验。具体机械手型号、端口设备名、回包与行终止符仍需确认。

## 报文与结果编码

`visionprep/protocols.py` 包含 MBAP、事务号、单元号、功能码、长度、异常帧和写回显的检查，并处理 TCP 分段读取。标准依据见 [Modbus 官方规范入口](https://www.modbus.org/modbus-specifications)。

随附报文示例使用单元号 1、保持寄存器 0/1，是新增示例配置。结果码 `0 WAIT / 1 OK / 2 NG` 也是本项目新增约定；任务书没有规定这些值，现场 PLC 程序必须采用一致约定后才能使用。

客户端只在调用者显式进入其上下文时建立连接。离线演示仅生成报文字节与控制字符串。自动测试使用分段字节流替身，不访问实验室网段，不代表 PLC 已实机互通。

## 机械手指令

| 功能 | 任务书指令 |
|---|---|
| 回零 | `$h` |
| 吸气 | `M3S1000` |
| 吹气 | `M3S500` |
| 关闭气泵 | `M3S0` |
| 运动模式 | `m20g90g00` |
| 查询 | `?` |
| 点位 | `x20y20z20a20`（数值仅示例） |

`robot_move()` 要求调用者明确提供四轴范围；没有默认的真实机械行程。示例范围与九点坐标标为合成数据。原始培训基线含历史运动指令和坐标，实机接入前应重新确定本机行程、坐标系、缓冲高度和工具偏移，先手动核对再使用自动取放。

## 建议接入顺序

先分别确认相机、PLC、光源与机械手的型号和协议；采集新的标定点与标准位；以静态真实图像验证定位、ROI 和阈值；再核对运动坐标及 PLC 结果交互。保存每次输入图、参数、响应和结果，形成可复查的联调记录。

当前没有相机采集后端、具体光源协议、串口回包确认或 PLC 梯形图。它们被列为需要设备信息的接入工作，没有用任意数据代替这些部分。
